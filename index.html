앱 이름 — 에노피 (Enopy)

계획적인 포트폴리오로 짓는 나의 자산 지붕

  • 에셋(Asset, 자산)과 캐노피(Canopy, 숲 위를 덮는 나무 지붕)를 합친 이름. 정글 같은 세상에서 비바람을 막아 주는 지붕처럼, 내 자산이 나를 지켜 주는 구조를 만든다는 취지
  • 아이콘의 층층이 쌓인 E는 위로 갈수록 넓어지는 세 층이 커져 가는 자산의 지붕을, 세로 기둥이 그 지붕을 받치는 나를 의미
  • 스크린샷 AI 파싱 — 증권사 화면 캡처를 Gemini Flash-Lite로 파싱해 종목·수량·평가금액을 추출하고, 바로 저장하지 않고 검수 화면을 거쳐 사용자가 확정하도록 설계
  • AI 투자 비서 — 보유 종목·비중을 프롬프트에 실어 Gemini Flash로 분석. 화면은 실제 응답으로, 반도체 두 종목 64.7% 집중과 KODEX 200을 통한 간접 중복 보유를 근거와 함께 지적
  • 시장 인사이트 — 국내외 지수와 함께 주요국 기준금리(BIS)와 중앙은행 정책 발표(미 연준·한국은행)를 공식 출처에서 받아 갱신
  • 혜택 탭 · 리워드 광고 — AdMob 보상형 광고는 서버 SSV(Google 서명 검증)로만 크레딧을 지급하고, 일일 횟수·쿨다운·중복 콜백을 서버 트랜잭션 안에서 차단하도록 설계

주요 성과

  • 역할·도구 권한·모델을 분리한 서브에이전트 15종을 정의하고 메인 세션이 총괄하는 오케스트레이션 구조를 설계 (복잡한 작업 11종 opus, 배포 sonnet, 커밋 haiku)
  • 보안 승인 → 구현 → 코드 리뷰 → QA → 문서 정합성으로 이어지는 5단 게이트를 정의, 보안 민감 영역은 착수 전 설계 승인과 구현 후 diff 검수를 모두 통과해야 진행
  • Android와 iOS를 각각 네이티브로 개발하면서, Android 테스트가 만든 기대 결과를 iOS 테스트가 그대로 재현하는지 비교하는 방식으로 두 앱의 비즈니스 로직이 같게 동작하도록 검증
  • 배포 에이전트는 내부 테스트 트랙에만 업로드하도록 고정해 프로덕션 출시는 사람만 할 수 있게 하고, 서명 키·서비스 계정 키는 내용을 읽지 않고 존재 여부만 확인하도록 제한
  • 에이전트 기반 배포 파이프라인 운영: 빌드 검증 → 번들 서명 → Play 내부 테스트·TestFlight 업로드, 커밋은 allowlist·denylist·diff 검증을 거치는 전담 에이전트가 수행
  • PreToolUse 훅으로 iOS 빌드 전 Xcode 버전을 .xcode-version과 대조, 불일치 시 차단
  • Gemini(Vertex AI SDK) 기반 스크린샷 파싱·대화형 분석을 탑재한 앱으로, 7개월간 커밋 1,066건 · GitHub Issue 279건을 이 워크플로우로 처리
